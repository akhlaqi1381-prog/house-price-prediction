# house-price-prediction
# پیش‌بینی قیمت منزل

پروژه ساده یادگیری ماشین بر اساس ویژگی‌های ملک.

در این پروژه از دو مدل پیش‌بینی‌کننده **Linear Regression** و **Random Forest** استفاده شده و نتیجه این دو مدل با هم مقایسه شده‌اند.

## داده‌ها

داده‌های من شامل این ویژگی‌هاست:

- نام محله
- متراژ
- تعداد اتاق
- تعداد سرویس
- پارکینگ
- انباری
- آسانسور
- بالکن
- کابینت
- سال ساخت
- قیمت

تعداد داده‌ها ۱۰۰ عدد هست که مقدار کمی هست.

## مراحل کار

1. پاکسازی داده‌ها
2. ساخت مدل‌ها
3. آموزش مدل‌ها
4. بررسی نتیجه‌ها
5. اضافه کردن یک داده برای پیش‌بینی

سعی کردم train و test رو با CV ترکیب کنم و ایده جالبی بود. برای داده‌های زیاد شاید خیلی به درد بخوره.

چون در محیط خطی بودیم، از ارزیابی عملکردهای **MAE**، **RMSE** و **R²** استفاده شد.
